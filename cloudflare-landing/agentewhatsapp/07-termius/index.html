ETAPA 07 / MANUTENÇÃO

aprenda a atualizar e corrigir o que publicou.

Depois que o sistema está online, você precisa conseguir entrar no ambiente, ver o que aconteceu e fazer uma atualização sem improvisar.

ferramenta neste build: Termius

faça assim

01
Aprenda a entrar no ambiente.

O Termius é uma forma de acessar o computador onde o projeto está rodando. Use um acesso individual e protegido.

02
Documente como atualizar.

Tenha uma sequência simples para publicar uma nova versão, reiniciar o sistema e voltar à versão anterior se necessário.

03
Aprenda onde olhar quando algo falha.

Os registros de erro ajudam a descobrir em qual etapa o atendimento parou sem precisar adivinhar.

você pode seguir quando

Você consegue explicar como entrar, atualizar, verificar um erro e recuperar a versão anterior — mesmo que ainda precise consultar o passo a passo.

evite

Depender de senhas compartilhadas ou de comandos que só uma pessoa conhece. Operar bem é conseguir repetir o processo com segurança.
