ETAPA 05 / FLUXO

faça as partes trabalharem na ordem certa.

Agora juntamos o que já foi construído: a mensagem chega, o histórico é consultado, a tarefa de IA acontece e a resposta volta para a pessoa.

nome técnico dessa ligação: webhook

faça assim

01
Receba a mensagem.

Quando uma nova mensagem chegar, o sistema precisa reconhecer quem enviou e qual conversa deve ser aberta.

02
Busque apenas o contexto necessário.

Recupere o histórico que ajuda naquela tarefa e envie somente o necessário para a etapa seguinte.

03
Responda e registre.

Depois da tarefa, envie uma única resposta e guarde o que aconteceu para a próxima mensagem.

você pode seguir quando

Uma conversa de teste percorre o caminho inteiro sem perder histórico e sem enviar respostas duplicadas.

evite

Uma mesma mensagem não pode gerar duas respostas. Se algo falhar no meio, o sistema deve permitir descobrir onde parou.
