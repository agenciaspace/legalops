Etapa 03 · dados

Modele a memória no Supabase.

O banco dá continuidade à conversa sem depender de informação espalhada no código.

Faça assim

1. Separe as entidades.

Comece com contatos, conversas e mensagens. Guarde identificadores, conteúdo, direção, status e timestamps.

2. Restrinja o acesso.

Ative RLS, use a chave correta em cada ambiente e permita que cada serviço leia somente o necessário.

3. Defina retenção.

Decida o que será apagado, anonimizado ou exportado e registre o motivo de conservar cada campo.

Pronto quando

O backend recupera o histórico correto por conversa e consegue gravar uma mensagem sem expor a tabela publicamente.

Risco principal

Dados pessoais vazados por tabela pública, RLS ausente, chave privilegiada no frontend ou logs contendo conteúdo sensível.
